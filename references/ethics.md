# Ethics — influence vs manipulation

Psychological principles are dual-use: the same reframing that helps users understand faster can manipulate them. Run these tests on any feature using nudges, defaults, urgency, notifications, or loss framing. In a healthcare product, distrust and reactance cost far more than a missed conversion.

## Three quick tests

1. 😰 **Regret test** — If the user knew everything the product team knows, would they behave differently? If yes, reconsider.
2. 🎎 **Manipulation matrix** (Nir Eyal) — Would the maker use it, and does it improve the user's life? Aim to be a Facilitator.

| | Maker does **not** use it | Maker uses it |
|---|---|---|
| **Improves user's life** | 👔 Peddler | 💚 Facilitator |
| **Doesn't improve user's life** | 💊 Dealer | 🎮 Entertainer |

3. 🏴‍☠️ **Black Mirror test** — Imagine everyone using this feature all the time (second-order effects). Does the story end well? (cf. the Facebook "like" button)

## Second-order effects

Solving one problem can create a worse one downstream. Think through consequences to the second and third order before shipping behavior-shaping features.

## Humane product principles

All products should:
- ⏳ **Save time** instead of wasting it
- 👓 **Value attention** instead of interrupting whenever convenient — e.g. batch or summarize notifications rather than bombarding; if a user has ignored the last 20 notifications, the humane response is to acknowledge and back off, not push harder
- 💚 **Reflect human values** instead of only shareholder interests

Technology should enable people to do things they couldn't before — not keep them busy or secretly captive.
